# 오버나이트 후보 스크리너

종가에 사서 다음날 아침(시가)에 파는 전략에 맞는 **후보**를 좁혀 주는 1차 스크리너다.
결론(사라/팔아라)은 내지 않는다. 판단은 사용자가 한다.

## 절대 규칙

1. **출처 없는 숫자 금지.** 모든 시세 숫자는 `screener.py`가 받은 데이터(FinanceDataReader: KRX 시세 + 네이버 일봉)에서 나온다. 웹검색으로 보탠 정보는 URL을 붙인다. 모르면 "확인 필요".
2. **계산은 코드로.** 등락률·거래량 배수·과거 신호 통계는 스크립트 출력만 인용한다. 암산하거나 다시 계산해서 바꾸지 않는다.
3. **사실/해석 분리.** 데이터에 있는 건 `[사실]`, 판단은 `[해석]`.
4. **매매 신호 금지.** "매수 추천", "사세요", 목표가, 비중을 쓰지 않는다. "조건 통과 후보"와 "더 확인할 곳"만 쓴다.
5. **후보가 없으면 없다고 말한다.** 조건을 몰래 완화해 억지로 채우지 않는다. 완화하려면 어떤 값을 얼마나 바꿨는지 밝힌다.

## 절차

1. 실행 시각 확인 (KST). 권장은 15:00~15:15 — 종가 동시호가(15:20~15:30) 전에 후보를 본다. 장 마감 후에는 확정 종가 기준 복기용.
2. 스크립트 실행:
   ```bash
   python3 screener.py            # 기본 조건
   python3 screener.py --help     # 조건 바꾸기 (--min-amount 200, --top 15 등)
   ```
   데이터가 안 받아지면(네트워크 차단 등) 그 사실을 그대로 보고하고 멈춘다. 다른 출처의 숫자로 대신 채우지 않는다.
3. `reports/` 에 생긴 `.md` 리포트를 읽고, 상위 후보(최대 5개)마다 웹검색으로 **오늘 오른 이유**(공시·뉴스)를 찾아 URL과 함께 `[사실]`로 붙인다. 못 찾으면 "급등 사유 확인 필요".
4. 다음 날 일정(실적 발표, 보호예수 해제, 유상증자, 미국 동종주 실적)이 있으면 같이 표기.
5. 출력 구성:
   - 한 줄 요약: 조건 통과 n개, 기준 시각, 데이터 출처
   - 후보 표 (스크립트 표 그대로)
   - 후보별 근거: `[사실]` 지표·과거 신호 통계·급등 사유(URL), `[해석]` 리스크 포인트
   - "더 파볼 곳" 목록
   - 마지막 줄: 투자 자문 아님, 과거 통계는 미래를 보장하지 않음

## 스크리닝 조건 (기본값, 모두 `--옵션`으로 변경 가능)

| 단계 | 조건 | 이유 |
|---|---|---|
| 유니버스 | KOSPI·KOSDAQ 보통주, 스팩·리츠·우선주·관리종목 제외 | 갭 리스크·유동성 |
| 유동성 | 거래대금 ≥ 100억, 시총 ≥ 1,000억, 주가 ≥ 1,000원 | 동시호가·시가 체결 가능성 |
| 당일 강도 | 등락률 2~20% | 상한가 근처는 체결·갭 위험이 커서 제외 |
| 마감 모양 | 종가위치 ≥ 0.75, 윗꼬리 ≤ 0.30 | 고가 부근에서 버틴 마감 |
| 수급 | 거래량 ≥ 직전 20일 평균의 1.5배 | 관심 유입 |
| 추세 | 종가 > MA5 > MA20, MA20 이격 ≤ 25% | 상승 추세 안, 과열 제외 |

정렬: 이 종목에서 **같은 조건이 과거 250거래일 동안 떴던 날**의 익일 시가 수익률(왕복 비용 차감)
표본이 5개 이상인 종목을 먼저, 평균 순. 표본 부족은 ⚠ 표시.

비용 가정 기본값: 수수료 0.015%×2, 매도 거래세 0.20%(연도별로 바뀜, 확인 필요), 슬리피지 0.05%×2.

## 한계 (리포트에 그대로 밝힐 것)

- 장중 스냅샷은 동시호가에서 바뀐다. 실제 종가·시가는 다를 수 있다.
- 과거 신호 통계는 종목별 표본이 작다. 생존 편향(지금 상장된 종목만 봄)도 있다.
- 일봉에는 거래대금이 없어 과거 신호의 거래대금은 종가×거래량으로 근사했다.
- 뉴스·공시·밤사이 해외 시장은 스크립트가 보지 않는다.
